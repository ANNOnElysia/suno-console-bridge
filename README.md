# suno-console-bridge

这是一个用来把本地音频直接传到 Suno 的轻量工具。

之前网上的脚本很多要把登录信息同步到别人的服务器（比如 sunouploader.site），总让人觉得账号凭据不太安全。这个项目把整套流程改成了纯本地运行，数据只在你的浏览器和本地电脑之间流动，不会经过任何第三方中转。

项目包括两部分：一个用于同步登录态和直传的油猴脚本，和一个本地跑的简易 Web 界面（另外也支持直接在终端用命令行上传）。

### 它是怎么工作的

简单说就是：
1. 你在浏览器打开 suno.com 并登录，油猴脚本会拿到登录后的 Token，并通过浏览器存储把它同步给运行在 localhost:3000 的本地服务。
2. 当你要上传音频时，本地界面向 Suno 官方接口申请一个 S3 上传地址。
3. 浏览器拿到地址后，直接把本地音频文件二进制上传到 Suno 的 S3 存储桶里，不走任何第三方服务器。
4. 传完后再调一次 Suno 接口确认入库。如果生成时触发了人机验证，脚本会从 Suno 页面里抓取现成的验证状态带过去。

### 怎么用

1. 启动本地服务：
   需要 Python 3 环境，不需要装任何额外的 pip 包。
   python3 server.py

2. 装脚本：
   把目录下的 userscript.user.js 内容复制到 Tampermonkey（油猴）插件里保存。

3. 登录并上传：
   一个标签页打开 suno.com 登录账号。
   另一个标签页打开 http://localhost:3000。
   看到状态显示已连接后，把音频文件拖进去，点上传就行。

### 命令行使用

如果你不想开 Web 界面，只要浏览器里同步过一次凭据，本地就会生成一个 auth_cache.json。之后你可以直接在命令行操作：

查看凭据状态：
python3 cli.py status

直接上传音频：
python3 cli.py upload /path/to/music.mp3 --title "歌曲名字" --tags "pop, rock"

### 注意事项

- 本地生成的 auth_cache.json 存着你的登录凭据，不要把它发给别人或者提交到公共仓库。
- 仅供个人学习和技术交流使用。
