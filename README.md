# suno-console-bridge

用于 Suno 平台音频直接上传与登录凭据本地同步的工具。

许多第三方脚本通常要求将用户登录信息同步至外部远程服务器，这可能带来账号凭据泄露的隐患。本项目将整个上传与凭据同步流程重构为完全本地化闭环运行，所有网络请求和数据流动仅保留在用户浏览器与本地环境之间，不经过任何第三方服务器中转。

项目包含两部分：一个用于同步登录态和直传的油猴脚本，以及一个轻量级的本地 Web 控制台与终端 CLI 工具。

### 工作流程

1. 用户在浏览器中打开 suno.com 并登录账号，油猴脚本捕获当前会话的 Authorization 凭据，并通过浏览器本地存储将其同步至运行在 localhost:3000 的本地服务。
2. 在发起音频上传时，本地界面向 Suno 官方接口请求 S3 预签名上传地址。
3. 浏览器获取到该地址后，直接将本地音频文件以二进制流形式 PUT 上传至 Suno 官方的 AWS S3 存储桶，不消耗本地服务器中转带宽。
4. 文件上传完毕后，向 Suno 发送确认请求完成入库。如遇到生成人机验证，脚本会直接从 Suno 页面提取内部上下文完成验证。

### 如何使用

1. 启动本地服务：
   系统需具备 Python 3 环境，无需安装任何额外依赖包。
   ```bash
   python3 server.py
   ```

2. 安装油猴脚本：
   复制项目根目录下的 userscript.user.js 内容，在 Tampermonkey 等脚本管理器中新建脚本并保存。

3. 登录与直传：
   - 浏览器一个标签页打开并登录 suno.com；
   - 另一个标签页打开 http://localhost:3000；
   - 待页面状态显示连接正常后，将音频文件拖入上传区域，填写标题与风格参数后点击上传。

### 命令行使用

当浏览器完成初次凭据同步后，凭据将保存在本地 auth_cache.json 中。此后可脱离 Web 界面直接在终端进行操作：

查看当前凭据有效状态：
```bash
python3 cli.py status
```

使用命令行上传音频：
```bash
python3 cli.py upload /path/to/music.mp3 --title "歌曲名称" --tags "pop, rock"
```

### 注意事项

- 本地生成的 auth_cache.json 包含敏感登录凭证，请勿将其分享给他人或提交到公开代码仓库。
- 本项目仅供技术研究、学习与个人本地化管理使用。
